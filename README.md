# 資格勉強アプリ

中小企業診断士の学習を効率化するために開発している学習管理アプリです。

「机では演習に集中し、出先では弱点克服や学習計画に集中する」という学習スタイルを実現することを目的としています。

## 概要

中小企業診断士の学習を続ける中で、学習ログ・苦手論点・問題の正誤・ミス原因などの情報が、テキスト・ノート・スマートフォンのメモなどに分散していきました。

その結果、学習そのものよりも「記録を整理する」「過去の学習を振り返る」といった管理作業に時間を使う場面が増えていました。

そこで、普段の学習で行っている記録方法をベースに、学習情報を一元管理できるアプリとして設計しています。

## コンセプト

**「自由な入力 × 構造化された学習データ」**

ObsidianやiOSメモのように、その日の学習内容を自由に書き込める一方で、入力された情報から科目・学習時間・正誤・ミス原因などを構造化し、後から分析や復習に利用できる状態を目指しています。

最終的には、

**机では1秒も管理作業をせず、スマートフォンが「次にやるべきこと」を知っている状態**

を目指しています。

## 主な機能

### デイリー・ワークスペース

1日の学習内容を1画面にまとめて記録します。

自由記述をベースにしながら、以下の情報を学習データとして扱います。

- 学習科目
- 学習時間
- 学習内容
- 教材の進捗
- 問題の正誤
- ミス原因
- 振り返り

1日の学習が完了したタイミングでデータを確定し、学習時間や成績などの統計に反映します。

### 学習時間・教材進捗管理

早朝・昼・通勤・深夜などの時間帯ごとに、予定時間と実際の学習時間を記録します。

また、科目ごとに教材の進捗状況を管理し、

- テキスト完了
- 問題集1周目
- 問題集2周目
- 未着手

など、学習の進行状況を把握できるようにしています。

### ミス原因の分類

問題を間違えた際に、単純な「不正解」だけではなく、原因を分類します。

- **定義漏れ**：知識・暗記が不足している
- **解法**：問題を解くための手順や考え方が不足している
- **ケアレス**：計算ミスや確認不足など

単なる正答率ではなく、「なぜ間違えたのか」を後から分析できることを重視しています。

### 問題・苦手論点の管理

問題ごとに、

- 正誤履歴
- 習熟度
- 良問フラグ
- 解いた日付
- ミス原因

などを記録します。

さらに、苦手な論点と問題集の演習番号を紐付けることで、特定の弱点に関連する問題をまとめて復習できるようにしています。

### 弱点復習ビュー

隙間時間でも復習できるよう、学習データから対象を絞り込んで表示します。

例えば、

- 財務の計算問題
- 経済の苦手論点
- 定義漏れの問題
- 過去に間違えた良問

など、目的に応じて復習対象を抽出することを想定しています。

## AI活用

Gemini APIを利用し、蓄積された学習データを分析する機能を開発しています。

例えば、ミス原因の傾向から、

「今週は解法による失敗が多いため、問題演習を増やすよりも解法パターンの再確認を優先する」

といった学習方針を提案することを想定しています。

また、過去問のA/Bランク問題の取りこぼし状況などを分析し、目標点数に到達するために優先して取り組むべき論点を提示することを目指しています。

Gemini APIのキーをフロントエンドに直接持たせないため、APIサーバーを介してAIと連携する構成としています。

## フロントエンド

このリポジトリは資格勉強アプリのフロントエンドです。

学習記録を入力するためのワークスペースと、蓄積したデータを確認・分析・復習するためのUIを中心に実装しています。

### 画面設計

主に以下の画面・機能を想定しています。

- デイリーワークスペース
- 学習時間・進捗
- 問題履歴
- 苦手論点
- 復習ビュー
- 学習統計
- AIによる学習分析

「記録するための画面」と「復習・次の行動を決めるための画面」を分け、学習中の管理コストをできるだけ減らすことを意識しています。

## 設計上の考え方

### 自由記述と構造化の両立

学習ログを最初から細かいフォームに分割すると、入力そのものが負担になります。

一方で、完全な自由記述では後から集計や分析ができません。

そこで、

**入力時は自由に、分析時は構造化する**

という方向性で設計しています。

### 「正解したか」だけではなく「なぜ間違えたか」

学習効率を高めるには、単純な正答率だけではなく、失敗の原因を把握する必要があります。

そのため、問題の正誤とミス原因を別のデータとして扱い、復習やAIによる分析に利用できる構造を目指しています。

## 開発背景

中小企業診断士の資格試験を学習する中で、自分自身が実際に行っている学習記録や復習方法を整理し、それをソフトウェアとして再構成することを目的に開発しています。

既存の汎用的なノート・タスク管理ツールに学習方法を合わせるのではなく、

**「中小企業診断士の学習では、どの情報を残し、どのように振り返ると効率がよいか」**

という具体的な学習フローを起点に、必要なデータ構造やUIを設計しています。
